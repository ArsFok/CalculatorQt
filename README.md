# Калькулятор

Программа "Калькулятор" с тремя режимами работы: обычный, инженерный и программист.

## Сборка
1. Установите Qt Creator 5.0.2 или выше
2. Откройте `My_Calculator.pro`
3. Нажмите "Собрать проект"

## Структура проекта
- `src/` - исходные коды
- `releases/` - готовые версии программы
